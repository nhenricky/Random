# Secure Random Ruby

Um gerador simples de tokens em **Ruby**, utilizando hexadecimal.

## Como usar

Clone o repositório:

```bash
git clone SEU_REPOSITORIO
cd secure-random
```

Execute o arquivo:

```bash
ruby hex.rb
```

## Exemplo

O programa gera um token hexadecimal aleatório, por exemplo:

```text
7f3a91c4e82b106d5a7c3e9f24b8a1d6
```

Cada execução gera um token diferente.
